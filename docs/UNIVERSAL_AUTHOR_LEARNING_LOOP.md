# Universal Author Learning Loop

## Product law

QRE is learned by using it, and QRE learns the user by observing what they supply and what they repeatedly choose.

The first authored experience must therefore teach the product without requiring the user to understand QRE's internal vocabulary.

## First use

A new creator can enter a client and a mundane source record such as:

- 111 Elm St
- bathroom cleaned
- kitchen cleaned
- arrived 10:10 AM
- left 12:12 PM

The dashboard can offer a starter perspective such as gaming, spy, cyberpunk, or another user-selected lens.

That lens is not a domain author. It is initial rhetorical pressure applied to the same world/relationship machinery.

The generated experience is delivered as ordered cuts:

1. boot / entry
2. orientation
3. escalating state
4. meaningful relationship or discovery
5. endpoint / round state

The creator learns the product by seeing that ordinary facts can become an experience without learning a separate QRE workflow language.

## Observation loop

After the first experience, QRE should ask for another observation instead of asking the user to write an authorial prompt:

> Anything interesting happen?
> Notice anything odd?

Examples:

- 200 bottles of shampoo
- a cat kept watching
- one room was already spotless
- the client returned later
- the same red light stayed on

The answer becomes new supplied reality. It is not automatically a style preference and is never treated as a fact about anything not supplied.

## Return

Round 2 receives:

- prior world state
- prior experience identity
- prior authored cuts
- new supplied evidence
- learned creator preferences
- return context

The machine should then produce a materially different sequence because the new evidence changes the world model or its interpretation, not because a new domain-specific author was selected.

## Two learning streams

### World learning

QRE learns the evolving world:

`entities -> events -> relations -> recurrence -> changed state -> unresolved questions -> reentry`

World learning may change the interpretation of the experience, but it does not rewrite immutable source truth.

### Creator learning

QRE learns the creator's preferences from explicit selections, accepts/rejects, replay, and repeated interaction:

`compression -> explanation aversion -> callback affinity -> surprise -> acceleration -> revisit`

Creator learning is preference-only. It cannot create or alter world facts.

## Universal invariant

A service receipt, pet memory, relationship, wedding, restaurant, rave, place, business, travel memory, or physical object all use the same path:

`supplied reality -> world model -> relationship discovery -> observer simulation -> movie hypothesis -> sequence -> Mouth -> playable cuts -> memory -> return`

The domain changes the supplied world. The machine does not change.
