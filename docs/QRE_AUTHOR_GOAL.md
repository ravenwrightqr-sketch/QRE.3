# QRE AUTHOR — MASTER GOAL

**Status:** CANONICAL
**Date:** 2026-08-15
**Branch:** `elite-universal-rebuild-v10`

This is the single source of truth for what we are building with the QRE Author. Read this before changing the author, cognition, sequence system, contracts, compiler, memory, or diagnostics.

## 1. THE GOAL

QRE is building a **universal creative intelligence system**.

It is not a text generator. It is not a Coco writer. It is not a template engine.

The primary goal is:

> **Give QRE any meaningful human input and have it discover and compile the most compelling sequence hidden inside that reality.**

The input may concern:

- a person
- a pet
- a family
- a relationship
- a business
- a brand
- a product
- a home
- real estate
- a service
- a job
- a restaurant
- an event
- a community
- a memorial
- travel
- education
- entertainment
- an organization
- a place
- an object
- a personal memory
- almost anything else

The intelligence must remain universal.

## 2. GOAL 1 — UNIVERSAL SEQUENCE INTELLIGENCE

Goal 1 is the first and most important milestone.

Given one prompt, QRE should be able to create a **short, high-impact sequence of cuts** that makes the viewer want the next cut.

The output is not a paragraph.

It is not a chronological summary.

It is not a list of facts.

It is a movie hidden inside the input.

The desired feeling is:

> **I didn't expect that.**
>
> **What happens next?**
>
> **Oh shit.**

The sequence may be very short or somewhat longer. There is no sacred word count.

## 3. THE SEQUENCE STANDARD

The user is thinking in terms of **splicing film together**.

QRE must therefore reason about **how the sequence plays**, not merely what happened.

Example target behavior:

```text
Coco walks into the groomer.
Lawyer informed.
Pink bows attack.
The mirror reflects something gorgeous.
Oh. It's me.
Off to hit the town.
```

The exact wording is not canonical. The **behavior** is canonical.

Possible successful cuts may be:

```text
Lawyer informed.

Pink bows everywhere.

Mirror approved.

Oh. Me.
```

A cut may be two words, one sentence, or longer when the creative job requires it.

### The goal is NOT shortness.

The goal is:

> **maximum attention impact with minimum unnecessary explanation.**

A short cut succeeds when it creates a large amount of implied context.

## 4. WHAT MAKES A GREAT CUT

A great cut should do at least one meaningful thing to the viewer's state:

- create a question
- create a surprising image
- change an expectation
- expose a contradiction
- reveal character
- escalate
- reverse status
- reframe the previous cut
- reveal a hidden relationship
- create a callback
- create a consequence
- create a payoff

The important distinction is:

> **Information gain is not automatically attention gain.**

For example:

```text
Coco is male.
Coco is a poodle.
Coco loves treats.
```

These may be useful world facts.

They are not automatically a sequence.

The author must decide whether a fact changes the viewer's experience enough to earn a cut.

## 5. THE AUTHOR MUST DISCOVER THE MOVIE

QRE should transform:

```text
raw input
↓
understanding
↓
world model
↓
significance
↓
creative possibilities
↓
sequence choice
↓
attention-driven cuts
```

The system is not supposed to decorate a fact list.

It should discover:

> **What is unexpectedly interesting here?**

and then build a sequence around that discovery.

## 8. REALITY IS SACRED

QRE may creatively frame reality.

QRE may not silently invent reality.

The author must distinguish:

```text
FACT
OBSERVED EVENT
SOURCE MOMENT
MEMORY
RUNTIME/PRESENCE
INFERENCE
CREATIVE POSSIBILITY
```

Inference is not automatically truth.

Creative possibility is not automatically an event.

The author must not invent:

- people
- names
- relationships
- ownership
- physical actions
- object placement
- locations
- dates
- outcomes
- dialogue
- emotional states
- provider behavior

unless supported by the supplied world.

## 9. CHARACTER / SUBJECT GRAVITY

The temporary subject is the star of the current experience.

The service, business, task, location, object, or circumstance is the world the subject experiences.

The subject does not need to be named in every cut.

Once identity is established, repetition of the name has low attention value unless the name itself creates an effect.

The author should prefer:

```text
subject presence
attitude
choice
reaction
preference
contradiction
habit
status
callback
consequence
voice
```

over:

```text
Coco...
Coco...
Coco...
Coco...
```

## 10. SERVICE-WORLD RULE

A service provider is often **setting rather than protagonist**.

Examples:

```text
pet grooming → pet is the star
housekeeping → resident / guest / home is the star
pool service → homeowner / property is the star
repair → customer / object / problem is the star
wedding service → couple / guests / memory is the star
```

Database labels such as `owner`, `customer`, `client`, `groomer`, or `employee` are internal relationships.

The mouth should use lived relationships only when they improve the experience.

## 11. SEQUENCE INTELLIGENCE

A sequence is not a chronology.

```text
arrived
bow
bath
brush
left
```

is chronology.

A compelling sequence changes meaning as it moves:

```text
known
→
interesting
→
question
→
changed expectation
→
reframe / escalation
→
payoff
```

Those shapes are examples, not mandatory templates.

QRE must discover the appropriate shape for the material.

Possible sequence shapes include:

```text
reveal
escalation
mystery
comedy
horror
romance
status inversion
understatement
character contradiction
callback
quiet realization
absurdity
beauty reveal
relationship shift
```

There is no universal fixed beat count.

## 12. ATTENTION STATE

QRE should eventually track a compact viewer state such as:

```text
what the viewer knows
what the viewer expects
what the viewer wants
what remains unresolved
what just changed
what could change next
```

This state should guide the sequence without becoming a rigid beat template.

## 13. COMPRESSION

Compression is a creative decision, not a word-count rule.

The Brain should be capable of choosing between:

```text
full statement
compressed statement
fragment
implication
image
single-word hit
```

Example:

```text
Coco is afraid of the bow.

Bows again.

Bows.

Lawyer informed.
```

The winning form depends on **position in the sequence and the amount the viewer can infer**.

## 14. CREATIVE LEARNING

Experiments are how the QRE architecture learns.

A failed output should not merely produce a new phrase blacklist.

Instead ask:

```text
WHAT FAILED?
WHY DID IT FAIL?
WHAT GENERAL LAW DOES THAT REVEAL?
WHERE ELSE SHOULD THAT LAW APPLY?
```

Example:

```text
Observed:
"Coco barks."

Lesson:
raw activity is not automatically attention.

General rule:
A cut earns attention when it changes the viewer's state.
```

The same rule should then be tested on unrelated domains.

## 17. EVALUATION

A sequence should be evaluated on separate dimensions:

```text
TRUTH
WORLD UNDERSTANDING
SIGNIFICANCE
CHARACTER GRAVITY
NOVELTY
ATTENTION
SEQUENCE COHERENCE
COMPRESSION
CREATIVE SURPRISE
PAYOFF
MEMORY VALUE
```

Do not collapse all of these immediately into one score.

A sequence can be factual and still creatively dead.

A sequence can be short and still attention-poor.

A sequence can be creative and still untruthful.

We need to know which capability failed.

## 19. ARCHITECTURAL HYGIENE

The system must not become a junkyard of superseded ideas.

Rules:

1. Prefer an existing canonical abstraction before creating a new one.
2. If a new contract replaces an old one, document the replacement immediately.
3. Every new contract must have a clear purpose and owner.
4. Mark obsolete contracts as legacy before deletion.
5. Delete superseded files once dependency tracing proves they are unused.
6. Never create `V2`, `V3`, `V14`, `V15`, etc. merely to avoid making a real architectural decision.
7. Keep one canonical architecture index.

The cleanup registry is:

`docs/AUTHOR_ARCHITECTURE_INDEX.md`
