# PURE UNIVERSAL COGNITION

Status: CANONICAL ENGINEERING TARGET

## Definition

QRE crosses into pure universal cognition when an unfamiliar input can enter the system with no domain-specific authoring recipe and QRE can:

```text
SUPPLIED REALITY
  -> STRUCTURAL EVIDENCE
  -> RELATION / TENSION DISCOVERY
  -> CHARACTER / LENS READ
  -> COMPETING LATENT MOVIES
  -> SELECTED SEMANTIC TRAJECTORY
  -> CANONICAL BEAT GRAPH
  -> REALIZATION OBLIGATIONS
  -> MOUTH LANGUAGE
  -> TRUTH / ATTENTION / SEQUENCE GATES
  -> COMPLETED EXPERIENCE
```

The important property is not visual polish. It is causal ownership.

The same source meaning must survive the entire chain. Lower layers may realize, compress, reframe, or repair language; they may not silently invent a new semantic story.

## Three required capabilities

### 1. Performing

QRE must execute the discovered cognition as a sequence of perceivable changes.

A successful performance has:

- an opening grounded in supplied evidence
- meaningful movement between beats
- a real forward pull
- a source-derived endpoint
- no unsupported concrete events

### 2. Discovering

QRE must derive its central movie from evidence structure rather than from known domains, objects, examples, or hard-coded story recipes.

Discovery should be driven by:

```text
relationship strength
contradiction
recurrence
recontextualization potential
specificity
unexpectedness
endpoint dependency
information value
truth safety
```

### 3. Creating

QRE must create a language realization that is materially different across different realities while preserving the discovered semantic job.

Creativity is allowed in:

```text
framing
attitude
implication
metaphor
personification
status
juxtaposition
understatement
absurdity
compression
rhythm
```

Creativity is not permission to manufacture facts.

## Universal cognition laws

1. No domain-specific story routing in the universal author.
2. No example-specific semantic recipe in the Mouth.
3. No object vocabulary may determine salience by itself.
4. Lexical recognition is evidence, never authority.
5. One canonical semantic thread travels downstream.
6. The endpoint is source-derived and sequence-specific.
7. QRE discovers the movie; the model realizes language.
8. Acceptance must diagnose cognition separately from prose quality.
9. Rejected candidates become reusable failure patterns, not memorized story solutions.
10. New probes must be allowed to produce different latent movies.

## Cross-domain acceptance

A pure-universal test set must include realities with different structures, not merely different nouns. At minimum test:

- return / object / recontextualization
- technical failure / procedural history / consequence
- recurring human ritual / absence / changed context
- physical work / hidden evidence / changed decision

A passing system must produce different cognitive hypotheses for materially different realities.

## Failure signatures

```text
KEYWORD ASSEMBLY
  recognized nouns -> chosen story frame

EXAMPLE PARROTING
  new reality -> old movie shape

MEANING DRIFT
  RealityGraph movie != BeatGraph meaning != Mouth meaning

ENDPOINT COPYING
  final supplied detail appears without an earned path

MOUTH RE-PLANNING
  language layer invents the movie instead of realizing it

GENERIC CREATIVE SLUDGE
  beautiful / magical / unforgettable language without evidence gravity
```

Any of these means universal cognition has not been crossed yet.

## Permanent objective

The goal is not to make one benchmark unbeatable.

The goal is to make **new reality cause new cognition**.

That is the threshold.
