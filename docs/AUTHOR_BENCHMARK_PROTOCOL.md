# QRE AUTHOR BENCHMARK PROTOCOL

**Status:** ACTIVE  
**Branch:** `elite-universal-rebuild-v10`

This document defines what each author test is actually testing. The goal is to prevent memory/chapter experiments from being mistaken for universal-author failures or successes.

## COCO — UNIVERSAL BASELINE

`COCO` is the baseline creative-author benchmark.

It tests:

- subject gravity
- reality discipline
- creative discovery
- attention movement
- cut grammar
- implied subject presence
- service-as-stage behavior
- novelty
- avoidance of generic narration

A COCO failure is primarily a failure of the universal author, world model, truth ledger, or cut mouth.

The benchmark must not require a returning chapter. No previous chapter is assumed.

## COCO-RETURN — LIVING MEMORY

`COCO-RETURN` is a deliberate second-chapter benchmark.

It tests whether QRE can:

- remember the previous chapter
- recognize a recurring subject/object/relationship
- avoid replaying the previous movie
- make a returning detail mean something new
- use accumulated subject history
- preserve identity truth from memory
- apply learned creative preferences without becoming formulaic
- create continuity with changed meaning

A returning chapter may use information that is unavailable in the baseline test because that information exists in memory.

Example:

```text
CHAPTER 1
Coco resisted the bow and left happy.

CHAPTER 2
The bow returns.
The author must not simply replay the first resistance story.
The return should create a new relationship, joke, escalation, contrast, or payoff.
```

## MARIA — ORDINARY REALITY

`MARIA` tests whether QRE can make routine service material interesting without inventing facts.

The author must preserve supplied timestamps, tasks, sequence, and outcome while discovering a human or situational angle.

A boring job is allowed to remain a boring job in reality. The author makes the experience watchable through framing, specificity, rhythm, contrast, or consequence.

## HORROR / RAVE — GENRE ADAPTATION

These are universal-author genre tests.

The system must change attention behavior without creating separate hardcoded genre brains.

The genre is a lens over the world, not permission to invent arbitrary events.

## TEST INTERPRETATION

For every test, separate the result into four questions:

```text
1. WORLD TRUTH
Did the author stay inside supplied reality?

2. AUTHORSHIP
Did the author discover something interesting instead of summarizing?

3. ATTENTION
Does each cut create a reason to see the next cut?

4. CONTINUITY
When memory exists, did the new chapter evolve rather than repeat?
```

Do not judge a COCO baseline run by COCO-RETURN standards.
Do not judge COCO-RETURN without checking memory-specific behavior.

## DEVELOPMENT LOOP

```text
ONE ARCHITECTURAL HYPOTHESIS
        ↓
ONE TEST RUN
        ↓
READ RAW OUTPUT
        ↓
IDENTIFY THE ACTUAL FAILURE
        ↓
ADAPT THE MECHANISM
        ↓
RUN THE SAME BENCHMARK AGAIN
        ↓
THEN RUN THE NEXT BENCHMARK
```

Update the strategic author documentation after every 2–4 meaningful experiments.
