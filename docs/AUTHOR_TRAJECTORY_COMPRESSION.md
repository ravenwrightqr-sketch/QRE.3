# QRE Author · Universal Trajectory Compression

## Production status
Canonical additive capability. No legacy author system is restored by this layer.

## Problem
A semantic Beat Graph may request more realization cuts than the Mouth can legally realize as distinct viewer-facing moments. The failure mode must never be duplicate language or fabricated reality.

## Production law
A beat is a candidate trajectory position, not a mandatory caption count.

QRE must prefer:

`4 distinct legal cuts + exact payoff`

over:

`5 cuts with a repeated or source-restated line`.

## Current canonical path

`Reality → Cognition → Latent Movie → Beat Graph → Reality Envelope → Meaning Spine → Realization Strategy → Mouth Candidates → Deterministic Beam → Trajectory Compression → Attention → Cut Policy → Sequence Arc → Final Scenes`

## Boundary
The Mouth Beam may identify that a non-terminal pool has no distinct viable realization. In that case it may omit that beat from the selected realization path. Exact approved endpoints remain sovereign and may never be skipped.

The remaining production integration must project the selected `MouthSequencePath.candidates[*].beatOrder` back into the canonical `SequencePlay` and use that same compressed trajectory for Attention, Cut Policy, Sequence Arc, diagnostics, and final scene assembly.

## Source-restatement rule
Candidates marked `source-restatement` are not considered meaningful trajectory advancement unless they also demonstrate substantial semantic movement or new relational evidence. This prevents literal lines such as `Stole a blue bow.` from winning merely because they are grounded.

## Universal intent
The rule is domain-neutral. The same machine must work for pet memories, businesses, weddings, real estate, restaurants, horror, romance, social experiences, service receipts, memorials, and future QRE formats.
