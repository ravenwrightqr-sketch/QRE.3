# QRE AUTHOR — VIEWER MOMENTUM PROTOCOL

**Status:** CANONICAL
**Purpose:** the reusable cognitive law behind Goal 1 universal sequence intelligence.

## Master question

> Given everything the viewer currently believes, what is the strongest valid change QRE can make to that mental model right now that makes the next cut desirable, surprising, or necessary?

This is the central author question.

## Pre-cut interrogation

Before realizing any cut, the Brain privately asks:

1. What does the viewer already know?
2. What do they currently expect?
3. What is the strongest unresolved question or curiosity gap?
4. What surprising but coherent change can occur without inventing reality?
5. Why does that change matter specifically to the temporary subject?
6. What does the viewer want after seeing it?
7. What should remain unrevealed?
8. What becomes possible because of this cut?
9. If this cut is removed, what gets weaker?
10. Can the same mental-model change be expressed with fewer words or stronger implication?

## Cognitive state

The sequence tracks:

```text
known
expected
active question
curiosity gap
prediction shift
current want
unresolved
forward pull
payoff debt
```

These are not prose requirements. They are cognitive state variables used to select and order cuts.

## What makes a cut earn existence

A cut should materially change at least one of:

```text
knowledge
expectation
question
prediction
want
interpretation
tension
payoff potential
character meaning
```

True information is not automatically attention.

Baseline identity is not automatically sequence movement.

Chronology is not automatically story.

An emotion arc is not automatically a movie.

## Curiosity

A strong cut can create or sharpen a knowledge gap without immediately resolving it.

Example behavior:

```text
Lawyer informed.
```

The line can be tiny while implying a large unseen event.

Do not copy the phrase. Reuse the underlying mechanism: **compressed implication that widens a meaningful question**.

## Prediction and surprise

A strong sequence controls expectation.

The Brain should seek material that is:

```text
not fully predictable
but still coherent
```

Pure randomness is not creativity.

Predictable continuation is not attention.

The sweet spot is a meaningful model update.

## Forward pressure

After each cut, the viewer should have a reason to continue:

```text
want to know
want to see
want to understand
want to witness escalation
want to see the subject react
want to see the payoff
want to understand the contradiction
```

This can be curiosity, suspense, anticipation, humor, beauty, dread, or emotional investment.

## Reframing

A later cut should sometimes change the meaning of an earlier cut.

Examples:

```text
apparent threat → joke
ordinary object → memory
awkward moment → victory
fear → status
service detail → character reveal
```

Reframe is stronger than repetition because it changes the viewer's model rather than merely adding another fact.

## Counterfactual necessity

A candidate cut should survive the question:

> If I remove this cut, does the sequence become materially weaker?

Weak removal damage:

```text
none
```

Strong removal damage:

```text
setup collapses
question disappears
surprise becomes random
escalation loses pressure
reframe loses meaning
payoff becomes unearned
```

The Brain should prefer cuts with meaningful removal damage.

## Compression

Compression is not a word-count contest.

The Brain may choose:

```text
full sentence
compressed sentence
fragment
image
implication
single-word hit
```

The chosen form depends on:

```text
context
viewer knowledge
position in sequence
available inference
strength of implied meaning
```

The target is:

> maximum cognitive impact with minimum unnecessary explanation.

## Anti-crutch learning

When a strategy repeats, the system should learn the repeated mechanism—not merely blacklist words.

Example:

```text
fear → treat → happy
```

Lesson:

> generic transformation arc is becoming a crutch.

Not:

> ban the word happy.

The same anti-crutch principle generalizes across domains.

## Reality boundary

Creative freedom may:

```text
reorder
compress
juxtapose
reframe
escalate
imply
callback
change meaning through context
```

Creative freedom may not silently invent:

```text
people
names
relationships
physical events
actions
locations
object placements
dialogue
outcomes
```

unless supported by the supplied world or explicit memory/runtime state.

Every meaningful experiment should produce a general lesson:

```text
failure
→ mechanism
→ reusable law
→ cross-domain test
→ architecture
→ documentation
```

Never turn every failure into another phrase blacklist.
