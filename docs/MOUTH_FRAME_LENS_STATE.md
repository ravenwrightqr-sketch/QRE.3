# QRE AUTHOR · FRAME LENS BOUNDARY

The Author may select a **frame** before sequence discovery.

A frame is a lens, never the story.

```text
reality + accumulated memory
  ↓
interesting relationship / change
  ↓
FRAME or NONE
  ↓
sequence search
  ↓
mouth
```

## Frame rules

- `NONE` means the natural reality is the strongest lens; it is not a creativity failure.
- A selected frame must materially increase the possibilities available to the sequence search.
- The frame must arise from supplied evidence, contradiction, change, repetition, status, unresolved tension, relationship, or another grounded signal.
- The sequence engine invents the actual progression.
- The Mouth writes the actual viewer-facing language.
- Facts remain the durable source record and are never replaced by the frame.
- Repeated interactions should make the natural lens richer through accumulated memory rather than forcing a fresh genre skin.

For service receipts, the frame is allowed to turn routine work into a more interesting perspective—negotiation, operation, investigation, return, reveal, and similar lenses—without turning the receipt into a fixed domain template.
