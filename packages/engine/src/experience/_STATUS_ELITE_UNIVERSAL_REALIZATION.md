# ELITE UNIVERSAL REALIZATION — ACTIVE

This directory uses the universal causal realization path for customer-language prose.

Active authority:
- `universalCausalRealizer.ts`

Compiler substrate:
- `cognitiveExperienceCompiler.ts`
- `experienceCompilerV16.ts` (artifact substrate only)

The following are explicitly NOT customer-language authorities:
- `universalExperienceRealizer.ts` V1
- legacy narrative/creative/template realizers
- domain-specific prose branches

Rules:
1. Prompt evidence is authoritative.
2. Inferred participants are never promoted into customer prose unless the prompt explicitly names/describes them.
3. Locations and times are first-class evidence.
4. Cognitive plans may control reasoning, tone, and sequence, but do not supply factual story content.
5. The realization path is domain-neutral: no groomer, tattoo, nightlife, housekeeper, memorial, horror, or other vertical prose branch.
6. Creative lenses may change framing and rhetorical energy, not factual evidence.
7. Media references are evidence when present in the prompt/context and must never be invented.
