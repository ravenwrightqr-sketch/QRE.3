# ELITE UNIVERSAL COG — ACTIVE LANGUAGE AUTHORITY

Status: ACTIVE

This compiler-connected realization layer is the only customer-language authority for the cognitive experience compiler.

## Architecture

`prompt -> prompt world -> latent movie -> causal attention -> lens -> writer realization`

## Rules

- Prompt evidence has highest factual authority.
- Explicit people/participants exist only when the prompt names or describes them.
- A place is not an owner/homeowner/host unless explicitly stated.
- A business does not imply a customer, employee, owner, or manager unless the prompt supplies one.
- A house/property does not imply an owner lives there.
- `kids/children`, `family`, `guests`, `crowd`, etc. are only participants when explicitly present or explicitly described.
- Locations and times are first-class evidence.
- Creative lenses change framing, not facts, unless the prompt explicitly requests fiction/invention.
- Horror/darkness is a reusable narrative lens, not a Halloween-only domain.
- Memory is accumulated semantic state, not a story template.
- No domain-specific groomer/tattoo/nightlife/restaurant/etc. branches belong in this authority.
- Legacy realizer files may remain physically present only until dependency proof allows deletion; they must not be imported by the active path.

## Do not re-connect legacy authorities

`universalExperienceRealizer.ts` is intentionally rebuilt in-place so the active import path remains stable while its implementation changes completely.

Anything named `V7/V8/V9/V10/V11/V12/V13/V14/V15/V16`, `creativeRealizer*`, `goldNarrativeRealizer`, `narrativeAttentionRealizer`, `phraseInventor*`, `transformationEngine`, or similar is **not** an authority for customer prose unless explicitly reintroduced through this file.
