# QRE Universal Compiler

## STATUS
CANONICAL. This directory is now the single compiler surface for customer-language experience creation.

## Canonical pipeline

`prompt → cognition → evidence → reality model → creative realization → Moment[] → CinematicScene[]`

## Core law

**Universal prompting does not mean universal vocabulary. It means universal reasoning over whatever the prompt actually contains.**

The compiler reasons over open-ended reality primitives:

- entities
- events
- states
- relationships
- places
- times
- emotions
- source evidence

No industry, business, animal, relationship, wedding, horror, comedy, or service-specific compiler is allowed here.

## Provenance law

Observed prompt evidence outranks derived interpretation. Creative language is presentation, not factual evidence. Semantic directives are never customer-facing facts.

## Creative law

Tone is a lens, not vocabulary. Comedy, horror, romance, dark, cinematic, or any future lens must alter performance of the same underlying reality rather than replace the reality with domain templates.

## Runtime law

The compiler produces the existing runtime `Moment` and `CinematicScene` contracts. It does not create a parallel player/runtime architecture.

## Removed

The previous `concepts`, `cortex`, `meaningEngines`, `models`, `semantic`, and legacy compiler acceptance stacks were removed from this branch because they created competing semantic authorities and template-shaped realization paths.

## Gate

The only compiler acceptance gate is:

`pnpm --filter @qre/engine test:universal-reality`

Failures in that lab are compiler failures. Do not add another domain-specific acceptance suite instead of fixing the universal machinery.
