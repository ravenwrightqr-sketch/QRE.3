# Compiler stress gates

`universalCognitiveMindAcceptance.ts` is the correctness floor: it protects reality fidelity, identity, memory resolution, ambiguity handling, state persistence, creative provenance, and runtime alignment.

`creativeSuperstarAcceptance.ts` is the quality stress gate. It deliberately spans mundane, social, romantic, horror, comedy, service, commerce, objects, sparse prompts, temporal prompts, surreal prompts, and multi-event prompts. It checks anchor conservation, generic-language avoidance, creative provenance, output diversity, recurrence state, and learned creative-lens adaptation.

Passing this suite does not mean QRE is universally better than a frontier general model. It means the specialization layer is enforcing the behaviors QRE is designed to optimize rather than merely checking compilation.
