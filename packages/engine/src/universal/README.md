# CANONICAL UNIVERSAL EXPERIENCE SECTION

This directory is the authoritative sentence compiler for the universal prompt system.

## Non-negotiable rules

- No domain-specific branches.
- Prompt wording is evidence; it does not become a category vocabulary.
- Explicit participants exist only when the prompt supplies them.
- A house is not assumed to belong to its occupants or owner.
- Locations, dates, and times attach to the event that supplied them.
- Creative phrasing may frame an observed event, but may not invent a new physical fact.
- The compiler should reason from events, relationships, change, and consequence.

## Legacy boundary

The older `experience/*` narrative compilers are not the authority for this section. Do not import them into the universal compiler. They remain only as historical/reference code until their consumers are retired.
